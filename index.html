Project Status

Use case

The form inputs of react-input-material as web components. Use them in plain HTML or with any framework, no React knowledge needed: text, numbers, dates, selections, code and rich text, checkboxes, files, time intervals, lists of inputs, sliders and tabs in Material Design, including validation.

Components included:

  • "text-input": Text, numbers, dates, selections, code and rich text.
  • "checkbox-input", "file-input", "interval-input" and "slider-input".
  • "generic-inputs": Dynamic lists of any of the inputs above.
  • "tab-bar" with "tab-item", "circular-spinner" and "generic-animate".

Quick start

Load the styles and the bundle, which contains all dependencies including React, and register the components:

<link
    href="https://unpkg.com/material-icons@1/iconfont/material-icons.css"
    rel="stylesheet"
/>
<link
    href="https://unpkg.com/react-input-material@latest/dist/index.css"
    rel="stylesheet"
/>
<script type="module">
    import {
        register
    } from 'https://unpkg.com/web-input-material@latest/dist/bundle/index.js'

    register()
</script>

<text-input
    declaration="Amount"
    maximum="200000"
    minimum="10"
    name="amount"
    required
    type="number"
></text-input>
<checkbox-input description="I agree" name="accepted" required>
</checkbox-input>

"dist/bundle/minimal/index.js" is a much smaller variant without code and rich text editor, tooltips and animated icons.

With a package manager

npm install web-input-material

All libraries web-input-material builds on are optional peer dependencies, since the bundle variants below already contain them. The default entry point expects them to be installed, including react-input-material's own dependencies, see react-input-material:

npm install \
    @rmwc/slider @rmwc/tabs clientnode core-js prop-types react react-dom \
    react-input-material react-transition-group web-component-wrapper

Register all components or only the ones you need:

import {register, TextInput} from 'web-input-material'

// All components:
register()
// Or only one:
TextInput.register()

To avoid installing anything else, import "web-input-material/bundle" or the smaller "web-input-material/bundle/minimal" instead, they contain all dependencies including React. Single components are available the same way, e.g. "web-input-material/bundle/components/IntervalInput".

Usage

Attributes

Each component accepts the properties of its React counterpart as attributes in kebab case, e.g. "initialValue" becomes "initial-value". Text properties take the attribute value as it is. All other attribute values are evaluated as JavaScript expressions, so strings inside them need quotes. Boolean properties are set by the presence of the attribute:

<text-input
    declaration="Choice"
    initial-value="'B'"
    name="choice"
    required
    selection="['A', 'B', 'C']"
></text-input>

<text-input
    editor="richtext"
    name="message"
    rows="6"
    theme-configuration="{primary: '#d55e5d'}"
></text-input>

All options are described in react-input-material.

Values and events

Read and write the current state via DOM properties like "value", "invalid" or "dirty". Validation states are also reflected as attributes, so you can style them with CSS, e.g. "text-input[invalid]". Changes are announced via a "change" event:

const input = document.querySelector('text-input[name="amount"]')

input.addEventListener('change', (event) => {
    if (event.target === input)
        console.log('New value', input.value, 'invalid', input.invalid)
})

input.value = 100

Development

yarn install
yarn start
yarn test

"yarn start" serves a playground with examples of all components.
