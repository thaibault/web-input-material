web-input-material 0.0.517

Project status

Use case

Reusable material design based input field with support for (richt-)text, code, selections, numbers, dates and so on.

Content

Installation

You can install via package manager, simply download the compiled version as zip file here and inject or request via CDN in HTML:

npm install web-input-material

Usage

Here you can see a complete initialization example.

import {
    api
} from 'https://unpkg.com/web-input-material@latest/dist/bundle/index.js'

api.register()
